# dog-walking

A product specification, OpenAPI contract, and reference API implementation for the **Stardogwalker** dog walking management platform — Cardiff, South Wales.

## Documentation

[docs/index.md](docs/index.md) is the source of truth for all documentation navigation — both humans and agents start there.

Published site: **https://datagriff.github.io/dog-walking/**

## Quick Start

```bash
task               # list all available tasks
task api:install   # install API dependencies
task api:test      # run all tests
task lint          # lint OpenAPI + AsyncAPI contracts
task docs:serve    # serve docs locally at http://localhost:8000
```
